# 诅咒剑草 MOD

基于开源项目 [CypressVillage/PvZ-Portable-Mods](https://github.com/CypressVillage/PvZ-Portable-Mods) 的本地二次开发。MOD 读取当前目录的《植物大战僵尸》正版 `main.pak` 和 `properties`，使用独立程序和独立存档。原版 `PlantsVsZombies.exe` 不会被替换。

本仓库仅发布源码与原创资源。首次使用请先按[仓库首页说明](../README.md)下载依赖并编译。

## 启动

- 双击游戏根目录的 `启动诅咒剑草MOD.bat`，进入 MOD 主菜单。
- 双击 `选择关卡启动MOD.bat`，输入 1–50，可直接进入任意冒险关卡。
- 在 PowerShell 中运行 `powershell -ExecutionPolicy Bypass -File EvilSwordMod\run.ps1 -Level 35`，也可从指定关卡进入。
- 第一次运行载入资源较慢，稍等游戏菜单出现。

独立存档位于 `EvilSwordMod\save`。原版 Steam 游戏的程序和存档不会被 MOD 启动器修改。

## 内容

植物、僵尸、图鉴、戴夫对白、菜单和关卡文字共 1132 个字符串键已经生成中文覆盖；菜单上原本绘在图片里的英文按钮另有中文覆盖。新增植物“诅咒剑草”在选卡界面和图鉴里，花费 175 阳光，冷却 30 秒。攻击前方一格，无视护甲；普通僵尸一刀，铁桶与橄榄球僵尸受到高额伤害，巨人僵尸两刀。任何僵尸接触本体或咬到一次就会触发诅咒，南瓜罩无效；蹦极抓取、小鬼啃咬和矿工背袭同样危险。

长篇图鉴、成就等文本含自动翻译，部分措辞还需要人工校对。若遇到英文残留或不自然的中文，请记录所在页面和原文，以便逐项修正。

新存档自动开放冒险模式后续内容、迷你游戏、生存模式、解谜模式、图鉴、植物和商店购买项，并提供 10 个卡槽。冒险关卡 1–50 可通过关卡启动器逐关进入。

| 按键 | 修改器功能 |
| --- | --- |
| F6 | 无限阳光：战斗时保持 9990 阳光 |
| F7 | 植物卡牌无冷却 |
| F8 | 普通植物无敌；诅咒剑草仍会触发诅咒 |

游戏画面底部显示三个开关的当前状态。开关默认关闭，每次启动重置。

## 你可以这样测试

1. 启动后检查主菜单、图鉴和选卡界面的中文，确认“诅咒剑草”显示 175 阳光与长冷却。
2. 用关卡启动器分别进入第 1、25、50 关；确认迷你游戏、解谜、生存和商店都可打开，卡槽数为 10。
3. 让普通僵尸从前方进入攻击范围，观察是否一刀击杀；再试铁桶、橄榄球、巨人僵尸，观察是否无视护甲及巨人两刀。
4. 让僵尸触碰诅咒剑草；再试南瓜罩、前排坚果、小鬼、矿工背袭与蹦极，确认本体一旦被触碰即消失。
5. 分别按 F6/F7/F8，确认底部状态切换、阳光数、卡牌冷却和普通植物受伤行为；打开 F8 后再检查诅咒剑草仍会枯萎。
6. 关闭游戏重新启动，确认独立存档保留全解锁状态。

如果遇到错误，请记录关卡、操作步骤和 `EvilSwordMod\save\userdata\log.txt`，以及画面上显示的文字。

## 开发与来源

运行 `powershell -ExecutionPolicy Bypass -File EvilSwordMod\build.ps1` 编译；成功后程序位于 `EvilSwordMod\build\pvz-portable.exe`。开源基础沿用 LGPL-3.0-or-later；代码修改位于 `EvilSwordMod\upstream`，MOD 清单与资源位于其 `mods\evilsword` 子目录。Dead Cells 的只读资源仅用于造型与设定参考，没有改动该游戏目录。

`EvilSwordMod\reference`、`backup`、`save`、`toolchain`、`venv` 和构建产物均为本机工作文件，包含用户自己的游戏资源或环境，不应随 MOD 公开发布。
